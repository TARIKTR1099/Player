## ✨ Features

### 🎵 Media Playback
- Audio: MP3, FLAC, WAV, OGG, AAC, M4A, WMA
- Video: MP4, MKV, AVI, MOV, WEBM, FLV
- Playlist management with shuffle/repeat modes
- Drag & drop file loading
- 10-band graphic equalizer
- Audio effects (reverb, delay, spatial, compressor, distortion)
- Spectrum visualizer + waveform display
- Subtitle timeline (SRT/VTT support)

### 🤖 AI Integration
- AI-powered plugin development assistant
- Multi-provider support: OpenAI, Anthropic, OpenRouter, Google AI
- Plugin security analysis (AI-driven code review)

### 🧩 Plugin System
- Plugin marketplace (browse, install, rate)
- AI-assisted plugin creation wizard
- GitHub publishing for plugins
- YouTube downloader plugin

### 🎨 Interface
- Dark/light themes
- Turkish & English language support
- Mini mode & fullscreen media mode
- Sidebar modes (full/icons)
- Keyboard shortcuts
- System tray integration

## ⌨️ Keyboard Shortcuts

| Key | Action |
|-----|--------|
| `Space` | Play/Pause |
| `Left/Right` | Seek ±5s |
| `Up/Down` | Volume ±5 |
| `M` | Toggle mute |
| `Ctrl+L` | Toggle lyrics/subtitles |
| `Ctrl+E` | Toggle equalizer |
| `Ctrl+F` | Toggle effects |
| `Ctrl+O` | Open file(s) |
| `F11` | Fullscreen media mode |
| `Esc` | Exit fullscreen |

## ⚡ Quick Start

```bash
# Download and run (Windows)
curl -LO https://github.com/TARIKTR1099/Player/releases/download/v1.0.0/Player.Setup.1.0.0.exe
./Player.Setup.1.0.0.exe

# Or clone and run from source
git clone https://github.com/TARIKTR1099/Player.git
cd Player
npm install
npm start
```
